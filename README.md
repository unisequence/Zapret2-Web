# Zapret2 WebControl

Локальная веб-панель для управления `zapret2`: единый интерфейс и API, а системные операции вынесены в платформенные бэкенды.

> **Статус проекта:** Windows-бэкенд управляет `winws2`. На Linux сейчас доступны общий каталог, редактирование профилей и списков, а также предпросмотр команды `nfqws2`; запуск и настройка firewall пока не реализованы.

[Быстрый старт](#быстрый-старт) · [Как это устроено](docs/ARCHITECTURE.md) · [Установка](docs/INSTALLATION.md) · [Руководство пользователя](docs/USER_GUIDE.md)

## Быстрый старт

Для первого запуска нужны Windows и интернет. Git не обязателен. Если Python 3.11+ ещё нет, установщик предложит установить его через WinGet.

1. Откройте [страницу релизов](https://github.com/unisequence/Zapret2-Web/releases) и скачайте **Source code (zip)** у нужного релиза.
2. Распакуйте архив в обычную папку пользователя и запустите `setup.bat`.

Установщик сам подготовит Python-окружение и необходимые файлы, затем запустит панель. При последующих запусках используйте `start.bat`. Откройте **http://127.0.0.1:8787**. Окно с панелью должно оставаться открытым; для остановки сервера нажмите `Ctrl+C`.

BAT-файлы запускают PowerShell со временным `ExecutionPolicy Bypass` только для этого процесса; постоянная политика Windows не меняется. Подробнее — [установка и устранение неполадок](docs/INSTALLATION.md).

## Возможности

| Раздел | Что можно делать |
| --- | --- |
| Стратегии | Просматривать и менять профили, включать/выключать, копировать и создавать свои |
| Настройки и скрипты | Смотреть активный движок, статус службы и подключённые Lua-библиотеки |
| Предпросмотр | Смотреть собранную команду и предупреждения до запуска |
| Списки | Просматривать и редактировать локальные доменные списки |
| Автолист | Редактировать список хостов вручную; автоматический детектор пока не подключён |
| Blockcheck2 | Запускать отдельную диагностику Windows с подтверждением |
| Журналы | Читать лог управляемого процесса и журнал диагностики |
| Автозапуск Windows | Устанавливать и управлять отдельной службой `zapret2-webcontrol` |

Текущий каталог содержит 34 профиля: 8 включённых и 26 выключенных. Эталонные профили нельзя удалить; можно выключить, изменить или скопировать их в пользовательский профиль.

## Безопасность и важные ограничения

- Веб-сервер слушает только `127.0.0.1`; в панели нет входа по паролю. Не выставляйте порт `8787` в локальную сеть и не проксируйте его наружу.
- Запуск `winws2` не происходит автоматически при запуске панели. Сначала показывается команда, проверяются предупреждения, затем `winws2 --dry-run`; запуск требует отдельного подтверждения.
- Панель останавливает только процесс или службу, которыми управляет сама. Чужие экземпляры `winws2` она не завершает.
- Для установки и удаления службы Windows нужны права администратора. Не держите административно запущенную панель открытой без необходимости.
- Blockcheck2 — отдельная диагностика: она временно меняет сетевое поведение Windows и использует WinDivert. Остановите другие DPI-инструменты и VPN; не запускайте Blockcheck2 параллельно с `winws2`.
- На Linux запуск `nfqws2`, настройка NFQUEUE и firewall намеренно заблокированы до появления безопасной установки правил с откатом.

## Где хранятся локальные данные

| Путь | Содержимое |
| --- | --- |
| `vendor/` | Закреплённый Windows-бандл и его файлы; не коммитится |
| `runtime/config/strategies.json` | Только пользовательские изменения и свои профили |
| `runtime/lists/` | Локальные списки |
| `runtime/blobs/` | Проверенные blob-ресурсы |
| `runtime/logs/` | Журналы работы и Blockcheck2 |

`vendor/`, `runtime/`, `.venv/` и кэши исключены из Git. Сделайте резервную копию `runtime/`, если хотите сохранить свои списки и настройки при переносе или переустановке.

## Разработка

В приложении нет сторонних runtime-зависимостей Python. Исходники находятся в `app/`, платформенные адаптеры — в `app/zapret2_webcontrol/backend/`, тесты — в `tests/`.

```powershell
$env:PYTHONPATH = "$PWD\app"
py -m unittest discover -s tests -t .
```
